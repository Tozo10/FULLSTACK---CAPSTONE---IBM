**CAR DEALERSHIP PROJECT**

This full-stack project was developed under the mentorship of IBM Skills Network. The frontend is built using React, while the backend is powered by Django, with MongoDB serving as the database. IBM Watson APIs have been integrated for seamless connectivity. Now, let me walk you through each component of my project.
